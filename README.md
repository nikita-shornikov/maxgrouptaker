# MAX Group Taker — добавление участников в группу MAX по имени

Скрипт автоматически добавляет пользователей в группу мессенджера MAX.
Открывает браузер, вы входите в свой аккаунт, и скрипт сам находит нужных людей и добавляет их.

---

## Что умеет скрипт

- Ищет пользователей по точному имени (например, "Борис" найдёт только Борисов, не Борисовых и не Бабушку)
- Добавляет всех найденных по этому имени в указанную группу
- Работает партиями по 10 человек
- После каждых 100 добавленных делает паузу 1 час (защита от блокировок)
- Поддерживает как инвайт-ссылки (`https://max.ru/join/...`), так и числовые ID групп

## Быстрая установка (рекомендуется)

Если просто нужно поставить на компьютер и пользоваться — используй установщик.

1. Скопируй папку проекта на компьютер (например в `C:\maxgrouptaker\`)
2. Правой кнопкой мыши кликни на файл **`INSTALL.ps1`**
3. Выбери **"Выполнить с помощью PowerShell"**
4. Установщик сам: проверит Python, создаст окружение, установит все пакеты, скачает браузер
5. На рабочем столе появится ярлык **"MAX GroupTaker"**
6. Дважды кликни на ярлык — программа запустится

> Если при запуске `INSTALL.ps1` появилась ошибка про политику выполнения — открой PowerShell и введи:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
> ```
> Затем запусти `INSTALL.ps1` снова.

## Установка с нуля (вручную, если установщик не сработал)

### Шаг 1 — Установить Python

1. Открой браузер и перейди на сайт **https://www.python.org/downloads/**
2. Нажми большую кнопку **"Download Python 3.x.x"** (возьмётся последняя версия)
3. Запусти скачанный установщик
4. **ВАЖНО:** на первом экране поставь галочку **"Add Python to PATH"** (внизу экрана)
5. Нажми **"Install Now"** и дождись окончания установки
6. Нажми **"Close"**

Проверка — открой PowerShell и введи:
```powershell
python --version
```
Должно написать что-то вроде `Python 3.12.0`. Если написало — Python установлен.

> **Как открыть PowerShell:** нажми Win + R, введи `powershell`, нажми Enter.

### Шаг 1.5 — Проверить и установить pip

pip — это менеджер пакетов Python, через него устанавливаются все зависимости. Обычно он идёт вместе с Python автоматически.

**Проверь, есть ли pip:**
```powershell
pip --version
```

Если написало что-то вроде `pip 24.0 from C:\...` — всё хорошо, pip есть, переходи к следующему шагу.

**Если написало ошибку "pip не является командой" — попробуй так:**
```powershell
python -m pip --version
```

Если это сработало — используй везде `python -m pip` вместо `pip`. Например:
```powershell
python -m pip install -r requirements.txt
```

**Если pip вообще не установлен — установи вручную:**

1. Скачай файл установки: перейди на **https://bootstrap.pypa.io/get-pip.py** и сохрани файл (Ctrl+S) в папку проекта
2. В PowerShell выполни:
   ```powershell
   python get-pip.py
   ```
3. Проверь что установился:
   ```powershell
   pip --version
   ```

**Если pip есть, но старый — обнови:**
```powershell
python -m pip install --upgrade pip
```

## Как узнать ссылку на группу

**Новый формат (инвайт-ссылка):**
1. Открой группу в приложении MAX
2. Зайди в настройки группы → "Пригласить участников" → скопируй ссылку
3. Ссылка выглядит так: `https://max.ru/join/LolSLTnooNt1JTupYV0FYrFNcV_uxUep8juxPZycAUs`

**Старый формат (числовой ID):**
1. Открой группу в [web.max.ru](https://web.max.ru)
2. Посмотри на адрес в браузере: `https://web.max.ru/-71285852438766`
3. Всё что после последнего `/` — это ID группы: `-71285852438766`

## Как работает поиск по имени

Скрипт ищет **точное слово**. Примеры при поиске "Борис":

| Контакт в MAX       | Добавится? |
|---------------------|-----------|
| Борис Иванов        | ✅ Да     |
| Борис               | ✅ Да     |
| Борисов Иван        | ❌ Нет    |
| Богдан              | ❌ Нет    |
| Бабушка             | ❌ Нет    |

Если нужно добавить всех Борисов **и** всех Богданов — запусти скрипт дважды, каждый раз с разным именем.

---

## Пауза каждые 100 участников

Чтобы не получить блокировку от MAX, скрипт автоматически делает паузу **1 час** после каждых 100 добавленных участников. В терминале будет видно:

```
Добавлено 100 участников. Пауза 60 мин. перед следующей партией...
  Возобновление через 60 мин.
  Возобновление через 59 мин.
  ...
Пауза окончена, продолжаем добавление...
```

Не закрывай терминал и браузер во время паузы.

## Запуск с параметрами (альтернативный способ)

Вместо `run.ps1` можно передать всё сразу в командной строке:

```powershell
python script2_web_add_to_group.py --chat-id "https://max.ru/join/TOKEN" --name "Борис"
```

Все параметры:

| Параметр      | Описание                                              |
|---------------|-------------------------------------------------------|
| `--chat-id`   | Ссылка на группу или числовой ID                      |
| `--name`      | Имя для поиска                                        |
| `--headless`  | Запустить браузер без окна (невидимо)                 |
| `--browser`   | Браузер: `chromium`, `firefox`, `webkit`              |
| `--config`    | Путь к файлу конфига (по умолчанию `config.yaml`)     |

## Частые проблемы

**Ошибка "python не является командой"**
→ При установке Python не была поставлена галочка "Add Python to PATH". Переустанови Python с этой галочкой.

**Ошибка про политику выполнения скриптов**
→ Введи перед запуском:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
```

**Браузер открылся, но скрипт ничего не делает**
→ Ты ещё не вошёл в аккаунт MAX. Войди в браузере — скрипт продолжит сам.

**Скрипт не находит кнопку "Добавить участников"**
→ Интерфейс web.max.ru мог обновиться. Открой `config.yaml` и обнови CSS-селектор `add_members_button`. Нужный элемент можно найти через F12 → Инспектор в браузере.

**Скрипт добавляет 0 человек**
→ Проверь правильность ссылки на группу и имени. Убедись, что ты — администратор группы.
